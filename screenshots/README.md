# Screenshots / Prototype Photos

This directory contains screenshots and interface captures of the VaaniSetu application.

- **`Onboarding.png`** — Initial user onboarding screen for setting up profile name and selecting preferred language.
- **`Phonetypecallscreen.png`** — Main dashboard displaying nearby connected peers list and primary mode selection triggers.
- **`languages.png`** — Multilingual selector dropdown demonstrating support for 10 regional Indian languages with instant UI localization.
- **`walkietalkie.png`** — Half-duplex Push-to-Talk (PTT) tactical channel mode screen with channel navigation and message history.
- **`CustomChannels.png`** — Dynamic channel creation dialog for establishing isolated tactical channels (e.g., Medical Team).
- **`FullDuplexCallMode.png`** — Hands-free, continuous full-duplex voice call interface with real-time speech transcription.
- **`Alert.png`** — Full-screen emergency distress override screen broadcasting high-priority audio alerts that bypass DND.
